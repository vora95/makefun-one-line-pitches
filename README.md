"Your Idea, Built Tonight" — a program that writes one short text to `/output/entry.txt`: one sentence that would convince a friend who has never coded to let an AI agent build their first app idea on make.fun. No jargon, no overpromising — just describe the app in plain words, and a working first version is ready to try tonight.

## Run it

```sh
node main.ts
```

Writes `/output/entry.txt` (189 characters, deterministic — the same bytes on every run). No network, no input.
